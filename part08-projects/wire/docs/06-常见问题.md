# 常见问题

汇总 Wire 使用过程中的常见问题和解决方案。

## 编译错误

### wire.go 未生成 wire_gen.go

**问题**：运行 wire 后没有生成 wire_gen.go

**原因**：
- wire.go 文件缺少 `//+build wireinject` 标签
- Injector 函数没有返回 nil

**解决方案**：

```go
//+build wireinject

package main

import "github.com/google/wire"

func InitializeApp() *App {
    wire.Build(NewConfig, NewDatabase, NewApp)
    return nil  // 必须返回 nil
}
```

### 找不到 Provider

**错误信息**：

```
wire: no provider found for *Database
```

**原因**：缺少 Database 的 Provider

**解决方案**：

```go
func InitializeApp() *App {
    wire.Build(
        NewConfig,
        NewDatabase,  // 添加 Database Provider
        NewApp,
    )
    return nil
}
```

### Provider 重复定义

**错误信息**：

```
wire: multiple providers for *Database
```

**原因**：同一个类型有多个 Provider

**解决方案**：

```go
// 移除重复 Provider
var Set = wire.NewSet(
    NewDatabase,  // 只保留一个
    // NewDatabase,  // 删除重复
)
```

### 依赖类型不匹配

**错误信息**：

```
wire: type *MySQLRepository is not assignable to type Repository
```

**原因**：接口绑定缺失

**解决方案**：

```go
var RepoSet = wire.NewSet(
    NewMySQLRepository,
    wire.Bind(new(Repository), new(*MySQLRepository)),  // 添加绑定
)
```

## 依赖图问题

### 循环依赖

**错误信息**：

```
wire: cycle detected:
A -> B -> C -> A
```

**原因**：组件之间存在循环依赖

**解决方案**：

```go
// 方案1：使用接口解耦
type BInterface interface {
    DoSomething()
}

type A struct {
    b BInterface  // 使用接口
}

type B struct{}

// 方案2：重构设计，提取公共部分
type Common struct{}

type A struct {
    common *Common
    b      *B
}

type B struct {
    common *Common
    a      *A
}
```

### 缺少依赖

**错误信息**：

```
wire: missing provider for Config
```

**原因**：依赖链中某个 Provider 缺失

**解决方案**：

```go
func InitializeApp() *App {
    wire.Build(
        NewConfig,  // 添加缺失的 Provider
        NewDatabase,
        NewApp,
    )
    return nil
}
```

### 无用依赖

**错误信息**：

```
wire: unused provider "NewCache"
```

**原因**：Provider 未被使用

**解决方案**：

```go
// 如果确实不需要，移除 Provider
var Set = wire.NewSet(
    NewDatabase,
    // NewCache,  // 移除未使用的
)

// 如果需要，添加使用该类型的 Provider
func NewService(cache *Cache) *Service {
    // ...
}
```

## 运行时问题

### 初始化失败

**问题**：Injector 返回错误

**解决方案**：

```go
func main() {
    app, cleanup, err := InitializeApp()
    if err != nil {
        log.Fatalf("初始化失败: %v", err)  // 处理错误
    }
    defer cleanup()
    
    app.Run()
}
```

### 清理函数未执行

**问题**：资源未正确释放

**解决方案**：

```go
func main() {
    app, cleanup, err := InitializeApp()
    if err != nil {
        log.Fatal(err)
    }
    
    // 确保清理函数执行
    defer cleanup()
    
    // 或在信号处理中执行
    quit := make(chan os.Signal, 1)
    signal.Notify(quit, syscall.SIGINT, syscall.SIGTERM)
    
    go app.Run()
    
    <-quit
    cleanup()
}
```

### 依赖未初始化

**问题**：组件使用时依赖为 nil

**原因**：Provider Set 未包含完整依赖

**解决方案**：

```go
// 检查 Provider Set 是否完整
var FullSet = wire.NewSet(
    NewConfig,
    NewDatabase,    // 确保 Database Provider 存在
    NewRepository,
    NewService,     // Service 需要 Repository
)
```

## 测试问题

### 无法注入 Mock

**问题**：测试时无法替换实现

**解决方案**：

```go
// 定义接口
type Repository interface {
    Find(id int) (*User, error)
}

// 生产 Provider Set
var ProdRepoSet = wire.NewSet(
    NewMySQLRepository,
    wire.Bind(new(Repository), new(*MySQLRepository)),
)

// 测试 Provider Set
var MockRepoSet = wire.NewSet(
    NewMockRepository,
    wire.Bind(new(Repository), new(*MockRepository)),
)

// 测试 Injector
func InitializeTestApp() (*App, func(), error) {
    wire.Build(
        MockRepoSet,  // 使用 Mock
        biz.ProviderSet,
        NewApp,
    )
    return nil, nil, nil
}
```

### 测试初始化复杂

**问题**：测试时需要手动构建依赖

**解决方案**：

```go
// 使用 Wire 简化测试初始化
func TestUserService(t *testing.T) {
    app, cleanup, err := InitializeTestApp()
    if err != nil {
        t.Fatal(err)
    }
    defer cleanup()
    
    service := app.Service
    // 测试 service
}
```

## Wire 命令问题

### wire 命令未找到

**问题**：运行 wire 报错 command not found

**解决方案**：

```bash
# 安装 wire
go install github.com/google/wire/cmd/wire@v0.6.0

# 确保 PATH 包含 Go bin 目录
export PATH=$PATH:$(go env GOPATH)/bin

# 验证安装
wire version
```

### wire 生成失败

**问题**：wire 生成报错

**解决方案**：

```bash
# 检查 wire.go 文件
cat cmd/server/wire.go

# 检查 build tag
//+build wireinject

# 运行 wire 查看详细错误
wire check ./cmd/server

# 生成代码
wire gen ./cmd/server
```

### wire_gen.go 未更新

**问题**：修改 wire.go 后 wire_gen.go 未更新

**解决方案**：

```bash
# 删除旧的生成文件
rm wire_gen.go

# 重新生成
wire gen ./cmd/server

# 或使用 go generate
go generate ./cmd/server
```

## 接口绑定问题

### 接口绑定错误

**错误信息**：

```
wire: wire.Bind: the first argument, the interface type, must be a pointer to an interface
```

**解决方案**：

```go
// 正确：使用 new(InterfaceType)
wire.Bind(new(Repository), new(*MySQLRepository))

// 错误：直接使用类型
// wire.Bind(Repository, *MySQLRepository)
```

### 多个接口绑定

**问题**：需要绑定多个接口到同一实现

**解决方案**：

```go
type Reader interface { Read() error }
type Writer interface { Write() error }

type File struct{}

var Set = wire.NewSet(
    NewFile,
    wire.Bind(new(Reader), new(*File)),
    wire.Bind(new(Writer), new(*File)),
)
```

## 清理函数问题

### 清理顺序不对

**问题**：资源清理顺序不正确

**原因**：Wire 按相反顺序清理

**解决方案**：

```go
// Wire 生成的清理顺序是：
// cleanup2() -> cleanup1()

// 如果需要特定顺序，手动管理
func NewApp(db *Database, redis *Redis) (*App, func(), error) {
    app := &App{db: db, redis: redis}
    
    cleanup := func() {
        // 先关闭 redis
        redis.Close()
        // 再关闭 database
        db.Close()
    }
    
    return app, cleanup, nil
}
```

### 清理函数未返回

**问题**：Provider 未返回清理函数

**解决方案**：

```go
func NewDatabase(cfg *Config) (*Database, func(), error) {
    db, err := sql.Open("postgres", cfg.DSN)
    if err != nil {
        return nil, nil, err
    }
    
    cleanup := func() {
        db.Close()
    }
    
    return &Database{DB: db}, cleanup, nil
}
```

## 多 Injector 问题

### 多个应用入口

**问题**：需要多个 Injector（如 server 和 worker）

**解决方案**：

```go
// cmd/server/wire.go
func InitializeServer() (*Server, func(), error) {
    wire.Build(ServerSet, NewServer)
    return nil, nil, nil
}

// cmd/worker/wire.go
func InitializeWorker() (*Worker, func(), error) {
    wire.Build(WorkerSet, NewWorker)
    return nil, nil, nil
}
```

### 共享 Provider Set

**问题**：多个 Injector 共享部分 Provider

**解决方案**：

```go
// 共享 Set
var CommonSet = wire.NewSet(
    NewConfig,
    NewDatabase,
    NewLogger,
)

// Server Set
var ServerSet = wire.NewSet(
    CommonSet,
    NewHTTPServer,
)

// Worker Set
var WorkerSet = wire.NewSet(
    CommonSet,
    NewWorker,
)
```

## 调试技巧

### 检查依赖图

```bash

wire check ./cmd/server

# 使用 wire diff 查看差异
wire diff ./cmd/server
```

### 查看生成代码

```bash
# 查看 wire_gen.go 内容
cat cmd/server/wire_gen.go

# 检查依赖顺序
grep -E "New[A-Z]" cmd/server/wire_gen.go
```

### 使用日志调试

```go
func NewDatabase(cfg *Config) (*Database, func(), error) {
    log.Printf("creating database with config: %+v", cfg)
    
    db, err := sql.Open("postgres", cfg.DSN)
    if err != nil {
        log.Printf("failed to open database: %v", err)
        return nil, nil, err
    }
    
    log.Printf("database created successfully")
    
    cleanup := func() {
        log.Printf("closing database")
        db.Close()
    }
    
    return &Database{DB: db}, cleanup, nil
}
```
