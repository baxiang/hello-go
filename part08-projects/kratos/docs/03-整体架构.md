## 3.2 核心数据结构

### 3.2.1 App 结构体

```go
// kratos/app.go
type App struct {
    // 上下文，用于通知退出
    ctx    context.Context
    
    // 取消函数
    cancel context.CancelFunc
    
    // 配置选项
    opts   *options
    
    // 等待组，用于等待所有服务退出
    wg     sync.WaitGroup
    
    // 互斥锁
    mu     sync.RWMutex
}

// options 包含所有可配置项
type options struct {
    // 服务器列表（HTTP、gRPC）
    servers []Server
    
    // 日志
    logger log.Logger
    
    // 名称
    name string
    
    // 版本
    version string
    
    // 元数据
    metadata map[string]string
    
    // 信号通道
    sigCh chan os.Signal
}
```

**图解 App 结构**：

```
┌─────────────────────────────────────────┐
│              App 结构                    │
├─────────────────────────────────────────┤
│                                         │
│  ctx: context.Context ───┐             │
│                           │             │
│  cancel: func() ──────────┼──▶ 退出控制  │
│                           │             │
│  opts: *options ──────────┼──┐          │
│                           │  │          │
│  wg: sync.WaitGroup ──────┼──┤ 同步控制  │
│                           │  │          │
│  mu: sync.RWMutex ────────┴──┴── 锁     │
│                                         │
└─────────────────────────────────────────┘
                    │
                    ▼
┌─────────────────────────────────────────┐
│           options 结构                    │

│                                         │
│  servers: []Server ──→ [HTTP, gRPC]    │
│  logger: log.Logger                     │
│  name: "my-app"                         │

│  metadata: map[string]string            │
│                                         │
└─────────────────────────────────────────┘
```

### 3.2.2 Server 接口

```go
// server.go
type Server interface {
    // Start 启动服务
    // 启动监听，开始接受请求
    Start() error
    
    // Stop 停止服务
    // 立即停止服务
    Stop() error
    
    // GracefulStop 优雅停止
    // 等待正在处理的请求完成后停止
    GracefulStop() error
}
```

**Server 实现类**：

```
Server 接口
    │
    ├── HTTPServer (HTTP 服务)
    │       │
    │       ├── network: "tcp"
    │       ├── address: ":8080"
    │       ├── timeout: 1s
    │       ├── router: *Router
    │       └── middlewares: []Middleware
    │
    └── GRPCServer (gRPC 服务)
            │
            ├── network: "tcp"
            ├── address: ":50051"
            ├── timeout: 1s
            ├── server: *grpc.Server
            └── unaryInterceptors: []grpc.UnaryServerInterceptor
```

### 3.2.3 Context 结构

```go
// context.go
type Context struct {
    // 请求
    Request *http.Request
    ResponseWriter http.ResponseWriter
    
    // 路径参数
    params Params
    
    // 请求路径
    path string
    
    // 方法
    method string
    
    // 原始数据
    data map[string]interface{}
    
    // 错误
    err error
    
    // 链路追踪
    traceInfo *TraceInfo
}
```

**Context 生命周期**：

```
请求到达
    │
    ▼
┌───────────────────┐
│  NewContext()    │  创建 Context
└───────────────────┘
    │
    ├── 设置 Request/Response
    ├── 设置 Path/Method
    │
    ▼
┌───────────────────┐
│  执行中间件链     │  使用 Context 传递数据
└───────────────────┘
    │
    ├── c.Set("key", value)  // 设置值
    ├── c.Get("key")        // 获取值
    ├── c.Param("id")        // 获取路径参数
    ├── c.Query("name")     // 获取查询参数
    ├── c.Body()            // 获取请求体
    │
    ▼
┌───────────────────┐
│  返回响应         │  使用 Context 返回
└───────────────────┘
    │
    ├── c.JSON(200, data)   // JSON 响应
    ├── c.String(200, "ok") // 字符串响应
    ├── c.Error(err)       // 错误响应
    │
    ▼
    请求结束，Context 销毁
```
