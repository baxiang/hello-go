## 前置知识

- Go 语言基础
- 分布式系统基本概念
- Docker 基础操作

## 学习建议

1. 按顺序学习理论文档，理解核心概念
2. 每学完一篇文档，动手完成对应 hands-on 练习
3. 完成基础学习后，实践 projects 中的项目
4. 遇到问题参考官方文档：https://etcd.io/docs/v3.5/
