# 一、为什么学习 Kratos？

在正式学习源码之前，我们先来了解一下 Kratos 是什么，以及它为什么值得学习。

## 1.1 Kratos 是什么？

Kratos 是 bilibili 开源的**微服务框架**，被誉为"B站微服务架构的基石"。它提供了一整套微服务开发解决方案：

```
┌─────────────────────────────────────────────────────────────────┐
│                         Kratos 能力矩阵                          │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   ┌─────────────┐  ┌─────────────┐  ┌─────────────┐          │
│   │   API 定义   │  │  代码生成   │  │   协议支持  │          │
│   │  (Protobuf)  │  │  (goctl)    │  │ gRPC + HTTP │          │
│   └─────────────┘  └─────────────┘  └─────────────┘          │
│                                                                 │
│   ┌─────────────┐  ┌─────────────┐  ┌─────────────┐          │
│   │   服务注册   │  │   负载均衡  │  │   熔断限流  │          │
│   │  (Registry) │  │ (Selector)  │  │ (Breaker)  │          │
│   └─────────────┘  └─────────────┘  └─────────────┘          │
│                                                                 │
│   ┌─────────────┐  ┌─────────────┐  ┌─────────────┐          │
│   │   链路追踪   │  │   配置管理  │  │   依赖注入  │          │
│   │  (Tracing)  │  │  (Config)   │  │   (Wire)   │          │
│   └─────────────┘  └─────────────┘  └─────────────┘          │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 核心能力说明

| 能力 | 说明 | 地位 |
|------|------|------|
| **API 定义** | 使用 Protobuf 定义 API | 业界标准 |
| **代码生成** | goctl 自动生成 CRUD 代码 | 提升效率 |
| **多协议支持** | 同时支持 gRPC 和 HTTP | 灵活部署 |
| **服务治理** | 熔断、限流、负载均衡 | 稳定性保障 |
| **可观测性** | 链路追踪、指标监控 | 运维必备 |

## 1.5 快速开始示例

### 1.5.1 安装

```bash
# 安装 Kratos
go install github.com/go-kratos/kratos/cmd/kratos/v2@latest

# 安装 goctl
go install github.com/go-kratos/kratos/cmd/goctl/v2@latest

# 验证安装
kratos --version
goctl --version
```

### 1.5.2 创建项目

```bash
# 创建新项目
kratos new helloworld

# 进入项目
cd helloworld

# 生成代码
go generate ./...

# 运行
go run .
```

### 1.5.3 简单示例

```go
package main

import (
    "github.com/go-kratos/kratos/v2"
    "github.com/go-kratos/kratos/v2/transport/http"
)

func main() {
    // 创建 HTTP Server
    server := http.NewServer(
        http.Address(":8080"),
    )
    
    // 注册路由
    server.HandleFunc("/hello", func(w http.ResponseWriter, r *http.Request) {
        w.Write([]byte("Hello Kratos!"))
    })
    
    // 创建应用
    app := kratos.New(
        kratos.Name("helloworld"),
        kratos.Server(server),
    )
    
    // 运行
    app.Run()
}
```
