# gRPC 学习系列

本系列文档系统性地介绍 gRPC 高性能 RPC 框架，从基础概念到生产实践。

## 学习路径

### 第一阶段：基础概念

| 文档 | 描述 | 预计时间 |
|------|------|---------|
| 01-gRPC概述 | gRPC 简介、Protocol Buffers、架构概览 | 40 分钟 |
| 02-Protocol-Buffers | Protobuf 语法、编译、最佳实践 | 60 分钟 |
| 03-Go客户端开发 | 服务端、客户端开发流程 | 50 分钟 |

### 第二阶段：进阶特性

| 文档 | 描述 | 预计时间 |
|------|------|---------|
| 04-流式RPC | 服务端流、客户端流、双向流 | 60 分钟 |
| 05-拦截器与中间件 | 拦截器、认证、日志 | 50 分钟 |
| 06-错误处理 | 错误码、错误传递、重试 | 45 分钟 |

### 第三阶段：生产实践

| 文档 | 描述 | 预计时间 |
|------|------|---------|
| 07-负载均衡 | 客户端负载均衡、服务发现 | 50 分钟 |

| 09-性能优化 | 连接池、流控、监控 | 45 分钟 |

## 前置知识

- Go 语言基础
- 网络编程基础
- Protocol Buffers 基础

## 学习建议

1. 先学习 Protocol Buffers 语法
2. 按顺序学习理论文档
3. 完成对应 hands-on 练习
4. 参考 official 文档：https://grpc.io/docs/
