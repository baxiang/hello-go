# 07-generics

泛型（Generics）是 Go 1.18 引入的革命性特性。Go 的泛型设计追求简洁与实用，不引入庞大的类型系统，而是为日常开发中最常见的代码复用问题提供类型安全的解决方案。

## 学习目标

- 理解为什么需要泛型，以及泛型解决什么问题
- 掌握类型参数、类型约束、类型集合的核心概念
- 能够使用泛型实现通用的数据结构和算法
- 熟练运用标准库的泛型包（slices、maps、cmp）
- 理解泛型与接口的选择原则
- 避免泛型使用中的常见陷阱

## 前置知识

- 掌握 Go 基础语法（变量、函数、类型）
