## 常见问题

**Q: 性能优化的优先级如何？**
A: 先优化瓶颈（CPU/内存/IO），再优化次要问题。数据驱动，不要过早优化。

**Q: 如何判断是否需要优化？**
A: 性能指标不达标、用户体验差、资源利用率低、成本过高等场景。

**Q: 性能优化的边界在哪里？**
A: 权衡开发成本、维护成本、性能收益。过度优化可能得不偿失。

**Q: 生产环境如何安全优化？**
A: 灰度发布、监控指标、快速回滚、A/B测试。
