# Part 05: 项目实战

本部分通过真实项目案例，将前面学到的Go语言知识应用到实际开发中。

## 学习目标

完成本部分学习后，你将能够：

- 使用主流框架开发微服务应用
- 掌握配置管理、日志、缓存等工程化实践
- 理解 RPC 通信和消息队列的使用
- 具备监控、告警和可观测性建设能力

## 学习建议

1. **循序渐进**: 建议按阶段学习，每个阶段打好再进入下一个
2. **动手实践**: 每个项目都要亲手运行和修改代码
3. **理解原理**: 不要只停留在使用层面，理解底层原理
4. **组合使用**: 尝试将多个技术组合使用，如 Redis + Kafka + gRPC
