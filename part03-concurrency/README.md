## 为什么 Go 并发如此重要？

Go 从诞生之初就将并发作为核心特性：

| 特性 | 说明 |
|------|------|
| **简洁的语法** | `go func(){}` 一行启动并发 |
| **轻量级协程** | 初始栈仅 2KB，可轻松创建数十万协程 |
| **高效调度** | GMP 模型，work-stealing 策略 |
| **通信顺序进程** | Channel 避免锁，代码更清晰 |
| **丰富的并发原语** | channel、sync、context 三大支柱 |

## 著名 Go 项目中的并发应用

| 项目 | 并发特点 | 并发规模 |
|------|----------|----------|
| **Kubernetes** | Controller 模式、Informer、WorkQueue | 数万 Pod |
| **etcd** | Raft 共识、MVCC、Watch | 数千节点 |
| **Docker** | Container 生命周期、Exec、Network | 百万容器 |
| **TiDB** | 事务调度、SQL 执行、PD 调度 | 分布式事务 |
| **Prometheus** | Scrape、Push、Alert | 百万指标 |
