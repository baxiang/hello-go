# Redis 学习系列

本系列文档系统性地介绍 Redis 分布式缓存系统，从基础概念到生产实践。

## 学习路径

### 第一阶段：基础概念

| 文档 | 描述 | 预计时间 |
|------|------|---------|
| 01-Redis概述 | Redis 简介、应用场景、架构概览 | 30 分钟 |
| 02-数据类型与操作 | String、Hash、List、Set、ZSet | 60 分钟 |
| 03-Go客户端基础 | go-redis 连接、配置、基本操作 | 40 分钟 |

### 第二阶段：进阶特性

| 文档 | 描述 | 预计时间 |
|------|------|---------|
| 04-持久化机制 | RDB、AOF、混合持久化 | 45 分钟 |
| 05-主从复制 | 复制原理、配置、运维 | 50 分钟 |
| 06-哨兵与集群 | 高可用架构、分片集群 | 60 分钟 |

### 第三阶段：实战应用

| 文档 | 描述 | 预计时间 |
|------|------|---------|
| 07-缓存设计 | 缓存策略、穿透、击穿、雪崩 | 50 分钟 |
| 08-分布式锁 | Redis 锁实现、Redlock | 45 分钟 |
| 09-性能优化 | 内存优化、慢查询、监控 | 50 分钟 |

## 前置知识

- Go 语言基础
- 网络编程基础
- Linux 基本操作

## 学习建议

1. 按顺序学习理论文档，理解核心概念
2. 每学完一篇文档，动手完成对应 hands-on 练习
3. 完成基础学习后，实践 projects 中的项目
4. 遇到问题参考官方文档：https://redis.io/docs/
